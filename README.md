# Stardance Orbit
A chrome extension that makes the current stardance site better by adding multiple features and improving UI/UX.

## Features

- Shop page reworked
  - created a new order button
  - replaced the categories on left and shop updates on right layout
  - categories is on top and shop updates come below it.
  - categories got a reworked look
  - wishlist items just got way better
  - there was sm bug when removing a wishlist item and adding one. fixed it, so that it only reloads the current page to show the changes rather than redirecting it to another page.
  - added goal tracking (depends on wishlisting items)
  - projected number of stardust so it shows how many hours left to work
  - individual or cumulative goals.
  - updated shop item card ui
  - added a progress bar to ever item card show how much more hrs needed to get that item
- Project page changes:
  - removed those three floating buttons
  - added ship button to the top
  - added inline devloging without needing to open a modal
  - stardust prediction depending on different factors(not too precise cuz of the originality factor)
  - inline devlog editing. instead of redirecting to another page
- added two themes, dark mode and light mode.

## Installation

**Load Unpacked**
1. Download the extension files from [releases](https://github.com/keerthi-officials/stardance-orbit/releases)
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked"
5. Select the extension folder
